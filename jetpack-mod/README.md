# Jetpack (NeoForge 1.21.1)

- Recipe (shaped): 3 Copper Ingots, 2 Netherite Ingots, 1 Lava Bucket
  ```
  C N C
  N L C
  ```
  (the bucket is returned empty)
- Wear it in the chest slot, hold Space to fly. No fall damage while thrusting.
- Fuel = durability (~5 min of thrust). Repair in an anvil with Netherite Ingots.

Build: `gradle build` (or use the Gradle wrapper from the NeoForge MDK). Jar ends up in build/libs.
Test: `gradle runClient`.
